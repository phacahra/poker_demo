# 🃏 Poker Lab — ระบบสาธิตโป๊กเกอร์ครบวงจร

เว็บสอน/สาธิต Texas Hold'em (static site, ไม่มี backend) — กติกา, กลยุทธ์, ตัวประเมินไพ่, คำนวณ Odds, และโต๊ะเล่นกับบอท AI

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | UI ทั้งหมด + กาว (โหลด engine, เรนเดอร์, ระบบแจ้งเตือนอัปเดต) |
| `poker-engine.js` | แกนหลัก: สำรับ, ตัวประเมินไพ่, Monte Carlo (pure functions) |
| `poker-game.js` | เครื่องยนต์เกม Texas Hold'em + AI บอท |
| `CHANGELOG.md` | **แหล่งข้อมูลจริง** ของบันทึกอัปเดต (เขียนด้วยมือ) |
| `gen-version.mjs` | สคริปต์แปลง `CHANGELOG.md` → `version.json` |
| `version.json` | ไฟล์ข้อมูลที่เว็บ fetch ไปแสดงป๊อปอัป "มีอะไรใหม่" (สร้างอัตโนมัติ อย่าแก้มือ) |

## รันในเครื่อง

```bash
python -m http.server 8777
# เปิด http://127.0.0.1:8777
```

## 🔔 ระบบแจ้งเตือนอัปเดต (What's New) — วิธีปล่อยเวอร์ชันใหม่

ระบบจะเด้งป๊อปอัปสรุปสิ่งที่เปลี่ยนให้ผู้ใช้เห็นอัตโนมัติเมื่อ `version.json` มีเวอร์ชันใหม่กว่าที่เขาเคยเห็น (จำผ่าน `localStorage`)

**ขั้นตอนเมื่อแก้โค้ดแล้วอยากปล่อยเวอร์ชันใหม่:**

1. เพิ่ม entry ใหม่ไว้ **บนสุด** ของ `CHANGELOG.md`:
   ```markdown
   ## v1.6.0 — 2026-07-05 — หัวข้อสั้น
   - อัปเดตอะไร 1
   - อัปเดตอะไร 2
   ```
2. รันสคริปต์สร้าง `version.json`:
   ```bash
   node gen-version.mjs
   ```
3. อัปทั้งโฟลเดอร์ขึ้นโฮสต์ (GitHub Pages / Netlify ฯลฯ)

เท่านี้ — ไม่ต้องแก้ `index.html` เลย ผู้ใช้เดิมทุกคนจะเห็นป๊อปอัปสรุปเฉพาะสิ่งที่ใหม่กว่าที่เขาเคยอ่าน

> เว็บ fetch `version.json` แบบ cache-busting (`?_=timestamp`, `no-store`) จึงเห็นเวอร์ชันใหม่ทันทีแม้ CDN แคช
> ถ้า fetch ไม่ได้ (เช่นเปิดผ่าน `file://`) จะใช้ค่า fallback ที่ฝังไว้ใน `index.html`

## เวอร์ชันปัจจุบัน

ดูได้ที่บรรทัดบนสุดของ `CHANGELOG.md` หรือ field `version` ใน `version.json`
